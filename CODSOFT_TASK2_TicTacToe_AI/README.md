# Tic-Tac-Toe AI

A human-versus-AI Tic-Tac-Toe game built using Python.

## Features
- Minimax algorithm
- Alpha-Beta Pruning
- Unbeatable AI with optimal play
- Win, loss and draw detection
- Input validation
- Automated unit tests

## Requirements
Python 3.8 or later. No external packages required.

## Run
```bash
py main.py
```

## Test
```bash
py -m unittest -v
```

## Algorithm
Minimax explores possible game states. The AI maximizes its score while assuming the human minimizes it. Alpha-Beta Pruning skips branches that cannot affect the final decision.
